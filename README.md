## Architecture

ST-LMS adalah Native HTML Market Geometry Intelligence Operating System — laboratorium observasi, perilaku, simulasi, replay, pengetahuan, governance, prediksi-empiris, dan audit yang berjalan penuh di browser tanpa backend.

**Core Philosophy:** Trade is Optional, Learning is Mandatory.

**Pipeline:**
```
BOOT -> MARKET -> TRUTH -> STRUCTURE -> EVIDENCE -> CLONE(x3) -> TRADE(x3) -> POSITION(x3)
-> STATISTICS -> BAG -> KNOWLEDGE -> PREDICTION -> TRADING SCHEMA -> GOVERNANCE -> CONSUMER
```
